About

The same live feed as the main map, shown in ArcGIS Online over CAL FIRE's official hazard and responsibility layers. Scores combine NASA FIRMS satellite detections, CAL FIRE and NIFC WFIGS incidents, and NWS fire weather alerts. A triage view, not an official warning: follow local authorities.

Source code on GitHub

How this ArcGIS map was built ArcGIS Online reads the pipeline's public files directly, so it is always current
  1. Pipeline publishes GeoJSON

    Every 3 hours a GitHub Actions run fetches the four sources, scores H3 cells and publishes feed.geojson, incidents.geojson and perimeters.geojson to GitHub Pages.

  2. Web map adds them by URL

    In ArcGIS Online Map Viewer each file is added with Add layer from URL as a GeoJSON layer. Nothing is uploaded: ArcGIS fetches the files (CORS-enabled) each time the map opens.

  3. CAL FIRE's authoritative layers

    Fire Hazard Severity Zones in SRA (FHSZSRA25_3) and Fire Responsibility Areas (SRA25_2) come straight from CAL FIRE's hosted feature services, the same ones behind its SRA Additions Viewer.

  4. Styled, shared, wrapped in an app

    Hexagons are styled by risk score, the map is saved and shared publicly, and an ArcGIS Instant App (Basic) adds the legend and layer list embedded here.
